# Software Requirements Specification

## Functional Requirements

### FR-1
The system shall visualize flight trajectories.

### FR-2
The system shall ingest historical and live flight data.

### FR-3
The system shall ingest weather information.

### FR-4
The system shall predict route deviation probability.

### FR-5
The system shall explain model predictions.

### FR-6
The system shall recommend optimized routes.

### FR-7
The system shall estimate fuel consumption.

### FR-8
The system shall estimate CO₂ emissions.

### FR-9
The system shall store prediction history.

### FR-10
The system shall expose REST APIs.

---

## Non Functional Requirements

- Fast response time
- High prediction accuracy
- Scalable architecture
- Secure API
- Easy deployment
